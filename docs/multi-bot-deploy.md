# 多账号部署：反向 WebSocket 与消息查重

本插件单账号部署无需额外配置。若你使用**多个 QQ 账号（主号 + 分身）**同时接入同一个 NoneBot 进程，同一条群消息会被推送给所有在该群的分身账号，导致每个 bot 都执行指令、都回复一份。本文说明连接方式与去重策略。

## 1. 反向 WebSocket 连接

NoneBot 侧（`.env`，机器人根目录）：

```dotenv
DRIVER=~fastapi+~httpx
HOST=0.0.0.0
PORT=3273
```

然后在 NapCat / go-cqhttp / LLOneBot 等 OneBot 实现里，**为每个账号各添加一条「反向 WebSocket」连接**，地址填写：

```
ws://你的公网服务器ip:<端口号>/onebot/v11/ws
```

每添加一个账号，该账号在其所在群里看到的所有群消息都会推送到这一个 NoneBot 进程。

## 2. 消息查重（避免重复回复）

同一物理群消息在多个账号上会被各自编号，`message_id` 并不可靠（同一消息在主号与分身上看到的值不同），因此不能按 `message_id` 去重。

推荐做法：部署配套插件 `nonebot_plugin_primary_bot`（独立于本插件仓库），在消息进入匹配器之前做**会话级去重**：

- 主号在场：优先由主号回复，分身等待约 1 秒确认主号已接管后让路；
- 主号不在该群：多个分身先到先得，只回复一次；
- 私聊天然不会重复，不参与去重。

主号通过环境变量 `MAIN_BOT_QQ` 指定（不填则回退使用 `SUPERUSERS` 中的第一个 QQ）。

```dotenv
MAIN_BOT_QQ=你的主号QQ
SUPERUSERS=["你的管理员QQ"]
```

## 3. 插件内适配

`/mp`（多人比赛）多图发送已做多 bot 适配：主号走合并转发，分身降级为逐张发送；配套查重插件未加载时自动按主号行为处理，不影响单账号部署。

> 修改配置后请重启 NoneBot 进程再验证。
